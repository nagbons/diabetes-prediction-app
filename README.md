# 🩺 Diabetes Prediction App

A machine learning-powered web application that predicts the likelihood of diabetes based on key medical and health-related features.  
Built using **Python, Scikit-Learn, and Streamlit**.

## 📌 Project Overview

This project is an end-to-end machine learning application designed to predict whether a patient is likely to have diabetes based on several medical indicators.

The system combines:
- Data preprocessing
- Exploratory data analysis
- Machine learning modeling
- Web application deployment

The goal is to demonstrate how predictive analytics can support early health-risk assessment and data-driven healthcare insights.

---

## 🧠 Machine Learning Workflow

1. Data Collection  
2. Data Cleaning & Preprocessing  
3. Exploratory Data Analysis (EDA)  
4. Feature Selection  
5. Model Training  
6. Model Evaluation  
7. Model Serialization using `joblib`  
8. Deployment with Streamlit  

---

## 📊 Features Used

The model predicts diabetes using the following medical features:

- Pregnancies
- Glucose Level
- Blood Pressure
- Skin Thickness
- Insulin
- BMI
- Diabetes Pedigree Function
- Age

## ⚙️ How It Works

1. User enters medical information into the web app  
2. The trained ML model processes the inputs  
3. The application predicts the likelihood of diabetes  
4. Results are displayed instantly through the Streamlit interface
